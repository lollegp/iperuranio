Shared memory for coding agents

Why is the cache
set to five minutes?

The code tells you how long. The reason was in a teammate’s chat. With iperuranio, your team commits reviewed decisions as Markdown in Git. Anyone on the branch can ask their own coding agent why.

Reviewed decisionABC-1250

Five minutes, down from ten

Product information stayed stale after updates. The team shortened the cache lifetime so customers would see changes sooner.

Earlier decision · ABC-1234

The team had raised max-age from two to ten minutes to reduce repeat requests to the origin.

Rejected alternativePAY-77

A timeout can follow a successful payment

A checkout timeout can arrive after the payment succeeds. Retrying every submission could charge a customer twice.

Open questionAUTH-29

No recorded reason for session storage

The login API reads its token from sessionStorage. The team found no historical explanation for choosing it over localStorage.

How a decision gets into Git

Draft in private

A compatible hook stages a decision while the conversation happens. Agents can also stage it through the CLI or MCP.

Review and commit

A developer checks the English record for accuracy and sensitive details, then commits the Markdown alongside the code.

Pull and search

A teammate pulls the branch and searches by ticket, file or symbol. The record shows the decision, its reason and any linked revision.
